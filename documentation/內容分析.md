# 普特共榮內容分析

來源：使用者提供的113頁PDF，圖片型文件。

原書四大架構：
- 師生溝通與互動技巧：第1–13張。面對爭論、挑戰與僵局，從暫停對話、保留尊嚴、清楚說理與傾聽開始。重點是建立信任，讓規範有機會被理解。
- 情緒管理與輔導支持：第14–25張。關注高敏感、完美主義與挫折反應。教師先穩定自己，再調整刺激、拆解目標與提供陪伴，並留意外在表現背後的負荷。
- 班級經營與行為規範：第26–38張。避免把資優身分變成比較或要求。透過去標籤、尊重意願、調整常規及同儕支持，建立有原則、也有彈性的班級生活。
- 親師合作與資源整合：第39–48張。親師合作從信任與共同語言開始。當問題超出單一教師的能力，連結資優班、輔導室、行政與其他專業資源，形成一致的支持方向。
- 緊急策略：第49–50張。當衝突已達臨界點，或教師感到心力交瘁，先暫停現場互動，再向資優班教師與輔導室尋求支持。

結構：前置資料1–9頁，50張策略牌卡10–109頁，空白牌卡110–113頁。
