# 普特共榮章節閱讀網站

開啟 `dist/index.html` 即可瀏覽，不需安裝程式或連上網路。

網站包含內容總覽、緣起與運用指南、四大主題、緊急策略、編輯資訊與空白牌卡，共8個HTML頁面。50張策略牌卡按照原書編號排列，每張分為情境、教師行動與核心心理。

各牌卡附有可展開的原文掃描頁與插畫。完整原始PDF保存在 `dist/source.pdf`。

章節分析是依原書整理的摘要，並非原書新增章節。轉錄文字已於2026-10-05逐頁對照原始圖片校對，保留原文措辭；原書本身的用字差異或重複語句列在「OCR校對紀錄.md」。完整逐頁文字另見「校對文字.md」。

網站已檢查桌面與手機版面、章節連結、圖像展開與鍵盤操作。

網站已設定於 GitHub Pages 公開發布：https://elvis0226.github.io/putegongrong/ 。儲存庫：https://github.com/elvis0226/putegongrong 。
